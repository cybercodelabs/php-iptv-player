# Deploy

Deployment guides for **PHP IPTV Player** / Guías de despliegue.

| Guide | Language | Target |
|-------|----------|--------|
| [Ubuntu + Nginx](ubuntu-nginx.md) | English | Ubuntu 22.04 / 24.04 LTS, Nginx, PHP-FPM, HTTPS |
| [Ubuntu + Nginx (ES)](ubuntu-nginx-ESP.md) | Español | Ubuntu 22.04 / 24.04 LTS, Nginx, PHP-FPM, HTTPS |

> [!IMPORTANT]
> The web server **document root** must point to the `public/` directory — never the repository root.  
> El **document root** del servidor web debe apuntar a `public/` — nunca a la raíz del repositorio.
